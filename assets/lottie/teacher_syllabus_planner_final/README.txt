Teacher Syllabus Planner - Final Lottie Package

Specs
-----
Canvas: 512 x 512
Duration: 6 seconds
FPS: 30
Background: transparent

Animation flow
--------------
1. Teacher enters with subtle sway.
2. Closed planner appears and opens.
3. Mathematics, Science, English cards enter separately.
4. Chapter rows appear.
5. Pen moves across the checklist.
6. Chapter checks complete one-by-one.
7. Calendar enters.
8. Progress bar fills with a real vector animation from 0 to ~70%.
9. Planned badge bounces in with sparkles.
10. Elements reset for looping.

Files
-----
teacher_syllabus_planner_final.json
  Standard Lottie JSON using the images/ directory.

teacher_syllabus_planner_final_embedded.json
  Single-file version with PNG assets embedded as data URIs.

images/
  External assets for standard JSON.

flutter_usage.txt
  Flutter usage snippet.

Recommendation
--------------
Use the standard JSON + images/ version for smaller JSON and easier asset replacement.
Use the embedded JSON when you specifically want one portable file.
