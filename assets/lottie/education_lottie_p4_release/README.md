# Education Document Lottie — P4 Final Release

Use `assets/lottie/education_document_final.json` as the default production animation.

Use `education_document_final_lite_30fps.json` when you prefer a smaller payload and lower animation frame rate.

## Flutter
Copy the `assets/lottie` folder into your Flutter project and add the JSON path under `flutter/assets` in `pubspec.yaml`.
A ready widget example is included in `flutter_example/lib/education_document_lottie.dart`.
