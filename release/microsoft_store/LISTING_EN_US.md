## Description

EduSheet is a teacher-focused question paper maker built for a larger Windows workspace.

Write questions naturally, add textbook-style maths without learning LaTeX, reuse questions from your local Question Bank, draw geometry, prepare OMR answer sheets, and export finished papers as print-ready PDF or editable Word documents.

The Windows edition is designed for physical keyboards, wide screens, and focused offline work. Your saved papers, Question Bank, templates, and preferences remain on your device. No EduSheet account is required for the core workflow.

Create complete papers in one place:

- Set school, exam, duration, marks, instructions, and header details.
- Compose MCQ, descriptive, numeric, true/false, fill-in-the-blank, and other supported question types.
- Insert visual fractions, roots, integrals, matrices, statistics, physics, and chemistry symbols inline.
- Reuse tagged questions without changing the saved master copy.
- Draw common geometry figures and coordinate content inside questions.
- Generate configurable OMR answer sheets.
- Preview supported PDF, DOCX, XLSX, CSV, PPTX, and text documents.
- Export normal question-paper workflows to PDF or editable Word.
- Use the built-in scientific calculator and teacher utilities.

EduSheet 1.2 is free to use. Premium purchases and subscriptions are disabled in this release. The application contains an inactive Store add-on integration for a possible future optional plan; it does not start a checkout while free-access mode is enabled.

Type Maths. Build Papers. Teach More.
